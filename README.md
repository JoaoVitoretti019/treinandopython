# 🐍 Exercícios Simples de Python

Este repositório reúne exercícios simples desenvolvidos em Python com o objetivo de praticar lógica de programação, estruturas de controle, funções e conceitos fundamentais da linguagem.

## 📚 Objetivo

O principal objetivo deste projeto é fortalecer meus conhecimentos em Python através da resolução de exercícios variados, explorando diferentes abordagens e soluções para problemas comuns de programação.

## 🚀 Conteúdos Praticados

- Variáveis e tipos de dados
- Operadores matemáticos e lógicos
- Estruturas condicionais (`if`, `else`, `elif`)
- Estruturas de repetição (`for`, `while`)
- Funções
- Listas, tuplas e dicionários
- Manipulação de strings
- Entrada e saída de dados
- Lógica de programação

## 📂 Estrutura do Repositório

```bash
📦 exercicios-python
 ┣ 📜 exercicio01.py
 ┣ 📜 exercicio02.py
 ┣ 📜 exercicio03.py
 ┗ 📜 ...

Cada arquivo contém um exercício independente, acompanhado de sua respectiva solução.

🛠️ Tecnologias Utilizadas
Python 3
▶️ Como Executar
Clone o repositório:
git clone https://github.com/seu-usuario/exercicios-python.git
Acesse a pasta do projeto:
cd exercicios-python
Execute o exercício desejado:
python exercicio01.py
